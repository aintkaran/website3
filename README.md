# aintkaran portfolio (website3 trial)

A static site. Vercel serves `public/` as-is. There is no build step and no image processing here.

## Where things come from
Everything under `public/assets/projects/` (WebP and JPEG XL exports, copied HEIC originals, per-project `meta.json` and `manifest.json`) and `.sync/state.json` is generated by a GitHub Action in the private `aintkaran/originals` repo. Do not edit those by hand; the next sync overwrites them. To add photos, change captions or reorder, work in `originals` (drag photos into a project folder on github.com and commit). The site updates a few minutes after the Action's green tick.

## What lives here
- `public/index.html`, `public/css/`, `public/js/gallery.js` - the hand-tuned front end.
- `public/config/site.json` - all site text and links (see `public/config/README.md`).
- `vercel.json` - output directory, clean URLs, and cache headers for images (browsers recheck after at most 1 hour) and fonts.
- `tests/README.md` - the manual gallery regression checklist.

`npm run dev` serves `public/` locally (needs `npx serve`).

## Notes
- Exports use sRGB, widths 600/1200/2400 capped at each photo's own width (a smaller photo ships at native size), WebP quality 90 and JPEG XL quality 90. Browsers that support JPEG XL get it; others get WebP. HEIC/HEIF photos are published unconverted under `original/` (Safari 17+ displays them natively) together with WebP previews under `web/` for browsers without HEIC support.
- The gallery scrolls horizontally by wheel, drag, touch or arrow keys; vertical touch stays native (pull-to-refresh). The full behaviour checklist is in `tests/README.md`.
- The pipeline's automated tests live in `originals` and run before every sync.
