# aintkaran portfolio (website3 trial)

A static site. Vercel serves `public/` as-is. There is no build step and no image processing here.

## Where things come from
Everything under `public/assets/projects/` (WebP and JPEG XL exports, `manifest.json`) and `.sync/state.json` is generated by a GitHub Action in the private `aintkaran/originals` repo. Do not edit those by hand; the next sync overwrites them. To add photos, change captions or reorder, work in `originals` (drag photos into a project folder on github.com and commit). The site updates a few minutes after the Action's green tick.

## What lives here
- `public/index.html`, `public/css/`, `public/js/gallery.js`: the hand-tuned front end.
- `public/config/site.json`: site text and links.
- `vercel.json`: output directory, clean URLs, and cache headers for images (browsers recheck after at most 1 hour) and fonts.
- `npm run dev` serves `public/` locally (needs `npx serve`).

## Notes
- Exports use sRGB, widths 600/1200/2400 (never upscaled), WebP quality 82 and JPEG XL quality 80. Browsers that support JPEG XL get it; others get WebP.
- `tests/README.md` is the manual gallery checklist. The pipeline's automated tests live in `originals`.
